# M1.3 – Exercises

These exercises use only what you learned in M1. Try them yourself before reading the guidance.

## Exercise 1 – Three lines

Create a program that prints three different lines of text.

### Guidance

You need three `print()` instructions. Put the text inside quotation marks.

### Possible solution

```python
print("I am learning Python")
print("The program has three instructions")
print("This is the last one")
```

Your text does not need to match this.

## Exercise 2 – Calculate with Python

Let Python calculate:

- 17 + 25
- 100 - 37
- 12 * 8
- 144 / 12

Try to calculate the answers yourself first.

### Possible solution

```python
print(17 + 25)
print(100 - 37)
print(12 * 8)
print(144 / 12)
```

## Exercise 3 – Make the result understandable

Improve this program:

```python
print(6 * 1.25)
```

Add text so another person can understand what the number means.

### Possible solution

```python
print("Cost of 6 units when each costs 1.25:")
print(6 * 1.25)
```

There are many good solutions.

## Exercise 4 – Find the syntax error

This code does not work:

```python
print("Python is useful)
```

What is missing?

### Solution

The closing quotation mark is missing:

```python
print("Python is useful")
```

Python will report a `SyntaxError`.

## Exercise 5 – Predict the result

What do you think these lines print?

```python
print(4 + 3 * 2)
print((4 + 3) * 2)
```

Write down your answer before running the code.

### Solution

The first produces `10`, because multiplication happens before addition.

The second produces `14`, because the parentheses make `4 + 3` happen first.

## Exercise 6 – Your first mini-project

Create a small program about a topic of your choice.

Requirements:

- at least four `print()` instructions
- both text and numbers
- at least two calculations
- at least one calculation using parentheses
- output that explains what the results mean

Run the program several times while building it. If you get an error, begin with the error type and the line Python points to.

There is no single correct answer for the mini-project.

You are ready for the next milestone when you can explain in your own words:

- what `print()` does
- why text normally appears inside quotation marks

- what a `SyntaxError` tells you

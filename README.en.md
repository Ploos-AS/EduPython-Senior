# EduPython-Senior

**Learn Python at your own pace.**

EduPython-Senior is a free and open Python course for adult and older beginners. It assumes **no previous programming experience** and no background in BASIC, COBOL, or any other programming language.

Norwegian is the primary language. English is a fully supported parallel language.

## Goal

EduPython-Senior teaches real Python from the ground up through calm progression, clear explanations, repetition, and practical examples relevant to everyday life.

This is not a reduced or simplified version of Python. The goal is genuine understanding and independence.

## Publishing

The course is published as four first-class formats from the same content source:

- Website
- EPUB
- Kindle-optimized edition
- PDF

All formats are available in both Norwegian and English.

## Teaching principles

- No prior knowledge required.
- One new idea at a time.
- Explain why before how.
- Real Python from the first lesson.
- Repetition is part of the learning design.
- Error messages are explained, not hidden.
- Examples should be relevant without stereotyping the audience.
- The course must be usable without depending on the website.
- Accessibility, readability, and e-ink are design goals.
- Norwegian terminology is paired with English terminology where useful.

## Initial learning path

- M0 – Welcome to programming
- M1 – Giving the computer instructions
- M2 – Remembering information: variables
- M3 – Talking to your program: input
- M4 – Making decisions: `if`, `elif`, `else`
- M5 – Doing things more than once: loops
- M6 – Functions
- M7 – Lists and dictionaries
- M8 – Files and folders
- M9 – CSV and simple data
- M10 – Practical automation and final project

Lessons should use this pattern where appropriate:

1. **Try it**
2. **Change it**
3. **Make it yourself**

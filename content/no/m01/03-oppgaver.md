# M1.3 – Oppgaver

Disse oppgavene bruker bare det du har lært i M1. Prøv selv før du ser på veiledningen.

## Oppgave 1 – Tre linjer

Lag et program som skriver ut tre forskjellige tekstlinjer.

### Veiledning

Du trenger tre `print()`-instruksjoner. Teksten skal stå mellom anførselstegn.

### Mulig løsning

```python
print("Jeg lærer Python")
print("Programmet har tre instruksjoner")
print("Dette er den siste")
```

Din tekst trenger ikke være lik denne.

## Oppgave 2 – Regn med Python

La Python beregne:

- 17 + 25
- 100 - 37
- 12 * 8
- 144 / 12

Prøv å regne ut svarene selv først.

### Mulig løsning

```python
print(17 + 25)
print(100 - 37)
print(12 * 8)
print(144 / 12)
```

## Oppgave 3 – Gjør resultatet forståelig

Forbedre dette programmet:

```python
print(6 * 1.25)
```

Legg til tekst slik at en annen person kan forstå hva tallet betyr.

### Mulig løsning

```python
print("Pris for 6 enheter når hver koster 1,25:")
print(6 * 1.25)
```

Det finnes mange gode løsninger.

## Oppgave 4 – Finn syntaksfeilen

Denne koden virker ikke:

```python
print("Python er nyttig)
```

Hva mangler?

### Løsning

Det avsluttende anførselstegnet mangler:

```python
print("Python er nyttig")
```

Python vil rapportere en `SyntaxError`.

## Oppgave 5 – Forutsi resultatet

Hva tror du disse linjene skriver ut?

```python
print(4 + 3 * 2)
print((4 + 3) * 2)
```

Skriv ned svaret før du kjører koden.

### Løsning

Den første gir `10`, fordi multiplikasjonen utføres før addisjonen.

Den andre gir `14`, fordi parentesen gjør at `4 + 3` beregnes først.

## Oppgave 6 – Ditt første miniprosjekt

Lag et lite program om et tema du velger.

Krav:

- minst fire `print()`-instruksjoner
- både tekst og tall
- minst to regnestykker
- minst ett regnestykke med parenteser
- output som forklarer hva resultatene betyr

Kjør programmet flere ganger mens du lager det. Hvis du får en feil, begynn med feiltypen og linjen Python peker på.

Det finnes ingen fasit for selve miniprosjektet.

## Før du går videre

Du er klar for neste milepæl når du kan forklare med egne ord:

- hva `print()` gjør
- hvorfor tekst vanligvis står mellom anførselstegn
- forskjellen mellom `print(2 + 3)` og `print("2 + 3")`
- hva en `SyntaxError` forteller deg
- hvorfor parenteser kan endre et regnestykke

Du trenger ikke huske alt utenat. Det viktige er at du kan prøve, lese resultatet og rette små feil.

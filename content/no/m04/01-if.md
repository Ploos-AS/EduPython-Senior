# M4.1 – Programmets første valg

Til nå har programmene våre fulgt samme vei hver gang. Nå skal programmet kunne bestemme om en instruksjon skal utføres.

## Et sant eller usant spørsmål

Se på uttrykket:

```python
temperatur < 0
```

Dette er et spørsmål Python kan svare **sant** eller **usant** på.

Hvis `temperatur` er `-5`, er uttrykket sant. Hvis temperaturen er `8`, er det usant.

## Prøv det

```python
temperatur = float(input("Temperatur: "))

if temperatur < 0:
    print("Temperaturen er under null.")

print("Programmet er ferdig.")
```

Hvis betingelsen etter `if` er sann, kjører den innrykkede linjen.

Hvis betingelsen er usann, hopper Python over den.

Den siste `print()`-linjen har ikke innrykk og kjøres derfor uansett.

## Innrykk betyr noe

I Python viser innrykk hvilke instruksjoner som tilhører `if`-blokken:

```python
if temperatur < 0:
    print("Under null")
    print("Vær oppmerksom på frost.")

print("Ferdig")
```

Begge de innrykkede linjene hører til `if`.

Innrykk er ikke bare pynt. Det er en del av Python-syntaksen.

## Sammenligninger

Python kan stille flere typer spørsmål:

```python
alder == 70
alder != 70
alder < 70
alder <= 70
alder > 70
alder >= 70
```

De betyr:

- `==` – er lik
- `!=` – er ikke lik
- `<` – mindre enn
- `<=` – mindre enn eller lik
- `>` – større enn
- `>=` – større enn eller lik

## = og == er forskjellige

Dette lagrer en verdi:

```python
alder = 70
```

Dette sammenligner to verdier:

```python
alder == 70
```

Tenk på `=` som **gi variabelen en verdi**, og `==` som **er disse like?**

## Endre det

Prøv:

```python
tall = int(input("Skriv et heltall: "))

if tall == 10:
    print("Du skrev 10.")

print("Takk.")
```

Kjør programmet med `10`, og deretter med et annet tall.

Endre så betingelsen til `tall > 10`.

## En vanlig feil: manglende kolon

Dette er feil:

```python
if tall > 10
    print("Større enn 10")
```

Python trenger kolon `:` etter betingelsen.

En slik syntaksfeil betyr at Python ikke klarer å lese programstrukturen. Se på linjen som feilmeldingen peker på, og kontroller spesielt `if`-linjen.

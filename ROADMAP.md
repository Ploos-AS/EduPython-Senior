- [ ] Publish M0 acceptance report.

### M0 acceptance criteria

M0 is complete when:

1. A learner can open the Norwegian M0 lesson and run the first Python program without prior programming knowledge.
2. Equivalent English content exists.
3. The same canonical course sources can produce website, EPUB, Kindle-targeted output, and PDF.
4. Example programs are automatically executed or syntax-checked in CI.
5. Generated book formats are checked automatically where practical.
6. Course content remains usable offline.
7. No essential teaching information depends only on colour, animation, hover state, or other web-only presentation.
8. Documentation clearly distinguishes course-content licensing from software/example-code licensing.

## M1 — First instructions

Introduce output, simple expressions, and the idea that programs are sequences of instructions.

## M2 — Variables

Introduce names, values, numbers, strings, and simple calculations.

## M3 — Input

Build small interactive programs using `input()`.

## M4 — Decisions

Introduce `if`, `elif`, `else`, comparisons, and Boolean thinking.

## M5 — Loops

Introduce repetition using `for` and `while`.

## M6 — Functions

Introduce decomposition, parameters, return values, and reuse.

## M7 — Collections

Introduce lists and dictionaries through practical examples.

## M8 — Files

Read, write, organize, and safely manipulate files and folders.

## M9 — Data

Use CSV and small real-world datasets without requiring advanced mathematics.

## M10 — Practical projects

Apply the course through useful automation and a learner-selected final project.

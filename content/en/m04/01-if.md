# M4.1 – The program's first decision

Until now, our programs have followed the same path every time. Now the program can decide whether an instruction should run.

## A true-or-false question

Look at the expression:

```python
temperature < 0
```

This is a question Python can answer as **true** or **false**.

If `temperature` is `-5`, the expression is true. If it is `8`, the expression is false.

## Try it

```python
temperature = float(input("Temperature: "))

if temperature < 0:
    print("The temperature is below zero.")

print("The program is finished.")
```

If the condition after `if` is true, the indented line runs.

If the condition is false, Python skips it.

The final `print()` line is not indented, so it runs either way.

## Indentation matters

In Python, indentation shows which instructions belong to the `if` block:

```python
if temperature < 0:
    print("Below zero")
    print("Be aware of frost.")

print("Finished")
```

Both indented lines belong to the `if`.

Indentation is not decoration. It is part of Python's syntax.

## Comparisons

Python can ask several kinds of questions:

```python
age == 70
age != 70
age < 70
age <= 70
age > 70
age >= 70
```

They mean:

- `==` – equal to
- `!=` – not equal to
- `<` – less than
- `<=` – less than or equal to
- `>` – greater than
- `>=` – greater than or equal to

## = and == are different

This stores a value:

```python
age = 70
```

This compares two values:

```python
age == 70
```

Think of `=` as **give the variable a value**, and `==` as **are these equal?**

## Change it

Try:

```python
number = int(input("Enter an integer: "))

if number == 10:
    print("You entered 10.")

print("Thank you.")
```

Run the program with `10`, then with another number.

Next, change the condition to `number > 10`.

## A common error: missing colon

This is wrong:

```python
if number > 10
    print("Greater than 10")
```

Python needs a colon `:` after the condition.

A syntax error like this means Python cannot read the program structure. Look at the line named by the error message and check the `if` line in particular.

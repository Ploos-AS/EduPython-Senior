## Hva er et program?

Et program er en samling instruksjoner som forteller datamaskinen hva den skal gjøre.

I Python kan en instruksjon være så enkel som:

```python
print("Hei!")
```

`print()` betyr at Python skal vise noe på skjermen.

## Prøv det

Skriv:

```python
print("Hei!")
print("Dette er mitt første Python-program.")
```

Kjør programmet.

Du skal se:

```text
Hei!
Dette er mitt første Python-program.
```

## Endre det

Bytt ut teksten med noe du selv ønsker å skrive ut.

For eksempel:

```python
print("God morgen!")
```

Kjør programmet på nytt.

## Lag det selv

Lag et lite program med tre `print()`-linjer som forteller:

1. navnet ditt eller et navn du finner på,
2. noe du liker å gjøre,
3. at du lærer Python.

Eksempel:

```python
print("Jeg heter Kari.")
print("Jeg liker å fotografere.")
print("Nå lærer jeg Python.")
```

Du trenger ikke forstå alle tegnene ennå. Det viktigste nå er å oppleve at du kan skrive en instruksjon, kjøre den og se resultatet.

## Nye ord

- **program (program)** – instruksjoner som datamaskinen kan utføre
- **kode (code)** – teksten vi skriver for å lage programmet
- **Python** – programmeringsspråket vi bruker
- **kjøre (run)** – be datamaskinen utføre programmet

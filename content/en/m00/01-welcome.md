Welcome to EduPython-Senior.

This course does not assume that you have programmed before. We start from the beginning and use real Python throughout.

## What is a program?

A program is a collection of instructions that tells the computer what to do.

In Python, an instruction can be as simple as:

```python
print("Hello!")
```

`print()` means that Python should show something on the screen.

## Try it

Type:

```python
print("Hello!")
print("This is my first Python program.")
```

Run the program.

You should see:

```text
Hello!
This is my first Python program.
```

## Change it

Replace the text with something you would like to print.

For example:

```python
print("Good morning!")
```

Run the program again.

## Make it yourself

Create a small program with three `print()` lines that tells:

1. your name or an invented name,
2. something you enjoy doing,
3. that you are learning Python.

Example:

```python
print("My name is Kari.")
print("I enjoy photography.")
print("Now I am learning Python.")
```

You do not need to understand every symbol yet. The important thing now is to experience that you can write an instruction, run it, and see the result.

## New words

- **program** – instructions that a computer can execute
- **code** – the text we write to create the program
- **Python** – the programming language we use
- **run** – ask the computer to execute the program

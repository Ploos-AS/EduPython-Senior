# EduPython-Senior

**Lær Python i ditt eget tempo.**

EduPython-Senior er et gratis og åpent Python-kurs utviklet for voksne og eldre nybegynnere. Kurset forutsetter **ingen tidligere programmeringserfaring** og ingen bakgrunn i BASIC, COBOL eller andre programmeringsspråk.

Norsk er hovedspråket. Engelsk er et fullverdig sidestilt språk.

## Mål

EduPython-Senior skal gjøre det mulig å lære ekte Python fra grunnen av gjennom rolig progresjon, tydelige forklaringer, repetisjon og praktiske eksempler som er relevante i hverdagen.

Kurset skal ikke være en redusert eller forenklet «seniorutgave» av Python. Målet er reell forståelse og selvstendighet.

## Publisering

Kurset skal publiseres som fire førsteklasses formater fra samme innholdskilde:

- Nettside
- EPUB
- Kindle-optimalisert utgave
- PDF

Alle formatene skal finnes på norsk og engelsk.

## Pedagogiske prinsipper

- Null forkunnskaper skal være nødvendig.
- Én ny idé om gangen.
- Forklar hvorfor før hvordan.
- Ekte Python fra første leksjon.
- Repetisjon er en del av læringsdesignet.
- Feilmeldinger skal forklares, ikke skjules.
- Eksempler skal være relevante uten å stereotypisere målgruppen.
- Kurset skal kunne gjennomføres uten å være avhengig av nettsiden.
- Tilgjengelighet, lesbarhet og e-ink skal være designmål.
- Norske fagbegreper introduseres sammen med engelske begreper der det er nyttig.

## Første læringsløp

- M0 – Velkommen til programmering
- M1 – Gi datamaskinen instruksjoner
- M2 – Huske informasjon: variabler
- M3 – Snakke med programmet: input
- M4 – Ta valg: `if`, `elif`, `else`
- M5 – Gjøre ting flere ganger: løkker
- M6 – Funksjoner
- M7 – Lister og oppslagsverk
- M8 – Filer og mapper
- M9 – CSV og enkle data
- M10 – Praktiske automatiseringer og sluttprosjekt

Hver leksjon bør så langt det passer bruke mønsteret:

1. **Prøv det**
2. **Endre det**
3. **Lag det selv**
